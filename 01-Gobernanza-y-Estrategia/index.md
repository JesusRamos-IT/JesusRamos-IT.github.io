# 📊 SGSI - Gobernanza y Estrategia

Este directorio constituye el núcleo del **Sistema de Gestión de Seguridad de la Información (SGSI)**, estructurado bajo el estándar **ISO/IEC 27001:2022**. 

Aquí reside la hoja de ruta técnica y administrativa que coordina desde la planificación estratégica hasta la ejecución operativa.

## 🏗️ Estructura del SGSI (Framework ISO 27001)

| Bloque ISO | Descripción | Acceso |
| :--- | :--- | :---: |
| **Gobernanza (4-6)** | Contexto, Liderazgo y Planificación de Riesgos. | [ Ver Bloque ](./06-Planificacion/) |
| **Soporte (7)** | Recursos, Competencia, Comunicación y Documentación. | [ Ver Bloque ](./07-Soporte/) |
| **Operación (8)** | Control Operacional y Tratamiento de Riesgos. | [ Ver Bloque ](./08-Operacion/) |
| **Evaluación (9)** | Seguimiento, Auditoría Interna y Revisión por la Dirección. | [ Ver Bloque ](./09-Evaluacion-Desempeno/) |
| **Mejora (10)** | No Conformidades y Mejora Continua. | [ Ver Bloque ](./10-Mejora/) |
