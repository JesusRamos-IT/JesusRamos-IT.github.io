# SGSI Lead Auditor Framework

Repositorio personal para la gestión y auditoría de seguridad de la información, alineado con el estándar **ISO/IEC 27001:2022**.

## 📁 Estructura del Repositorio

Este proyecto se organiza en bloques lógicos para facilitar la auditoría y la gestión documental:

*   **`01-Gobernanza-y-Estrategia/`**: Documentación de alto nivel (Cláusulas 4-10 de la norma).
*   **`02-Criterios-Anexo-A/`**: Implementación técnica y operativa de los 93 controles.
*   **`03-Plantillas-y-Toolkits/`**: Documentos maestros (SOPs, Informes de Auditoría, Registro de NCs).
*   **`_layouts/`**: Plantillas Jekyll para la renderización web.
*   **`Dashboard-SoA.md`**: Panel de control maestro y Declaración de Aplicabilidad.
*   **`index.md`**: Hub de navegación principal para la interfaz web.

## 🛠️ Entorno de Trabajo
*   **Gestión Documental**: Markdown (estándar).
*   **Renderizado**: GitHub Pages (Jekyll).
*   **Auditoría**: Basada en ISO 27001:2022 e ISO 19011.

## 🚀 Navegación
Para consultar el estado del sistema o realizar auditorías, accede al `Dashboard-SoA.md` o visualiza la web desplegada.
